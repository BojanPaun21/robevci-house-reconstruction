# robevci-house-reconstruction

Digital reconstruction of the interior of the Robevci House in Ohrid, North Macedonia.

A desktop application that lets users walk through a 3D model of the interior of the house and read information about selected exhibits. Built in Autodesk Maya and Unreal Engine 4.27 as part of a bachelor thesis at ISVMA (University of Information Science and Technology "St. Paul the Apostle").

## What it is

- A first-person walkthrough of one floor of the house: the entrance, two hallways and the blue room.
- Navigation with keyboard and mouse on a standard desktop computer.
- Information panels appear when you walk up to selected exhibits.
- The model shows the current museum display, not the historical interior. The carved ceilings were not modelled, and the scene uses Unreal Engine's default lighting.

## Run the application

1. Open the latest release and download the zip file.
2. Unzip it and run the `.exe` file.
